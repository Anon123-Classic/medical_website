# Medical Website

A full-stack healthcare web application built with **Django**, designed to provide a structured platform for accessing healthcare-related services and information.

##  Overview

This project is a web-based medical platform developed to demonstrate how modern web technologies can be used to build solutions for the healthcare sector.

The application combines a **Django backend** with HTML, CSS, and JavaScript to provide a functional and user-friendly healthcare website.

## 🚀 Features

* Healthcare-focused web interface
* User account management
* User authentication
* Database-driven application
  Responsive web interface
* Organized medical content
*  Django-based backend
*  SQLite database integration
*  HTML & CSS frontend
*  JavaScript-based interactions

##  Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/Anon123-Classic/medical_website.git
```

### 2. Navigate to the project

```bash
cd medical_website
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the virtual environment

**Windows:**

```bash
venv\Scripts\activate
```

**Linux/macOS:**

```bash
source venv/bin/activate
```

### 5. Install dependencies

```bash
pip install django
```

If a `requirements.txt` file is added later, use:

```bash
pip install -r requirements.txt
```

### 6. Run database migrations

```bash
python manage.py migrate
```

### 7. Start the development server

```bash
python manage.py runserver
```

Open the application at:

```text
http://127.0.0.1:8000/
```
